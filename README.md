# Seminarkanon 2026/2027

Top-10-Romanlisten aus dem Seminar 16480 „Die besten Bücher aller Zeiten? Kanonbildung im 21. Jahrhundert“ (FU Berlin, WiSe 2026/2027, Prof. Dr. Frank Fischer).

**Website:** https://lehkost.github.io/seminarkanon-2026-2027/

## Daten

`seminarkanon.json` enthält alle 40 Stimmzettel (Namen pseudonymisiert) mit Wikidata-IDs für Werke und Autor\*innen. Die Daten wurden händisch erfasst, angereichert und überprüft.

## Entstehung

Die Website (`index.html`) und das Skript zur Umwandlung der Listen in JSON wurden mit Claude (`claude-opus-5-5`) erstellt. Alle Ergebnisse wurden händisch geprüft und korrigiert.
